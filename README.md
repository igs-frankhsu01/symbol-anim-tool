# 簡易圖騰動畫產生器

線上操作介面：https://igs-frankhsu01.github.io/symbol-anim-tool/

網頁只是介面。拆圖、做 Spine、輸出都由使用者電腦上的「本機小幫手」（http://localhost:8810）呼叫 Photoshop 與 Spine 完成，檔案不會上傳。

本機小幫手安裝程式：[download/symbol-anim-helper.exe](download/symbol-anim-helper.exe)，下載後雙擊，照精靈按下一步。也可以下載 [ZIP](download/symbol-anim-helper.zip)，解壓後雙擊 install.cmd。

需要：Windows、Photoshop、Spine 3.8.99（Node.js、Python、ffmpeg 沒有的話安裝程式可以用 winget 自動安裝）。

這個 repo 由工具資料夾的 `web/build_site.js` 產生，請不要直接改。
